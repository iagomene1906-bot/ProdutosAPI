# 📦 ProdutosAPI

> Uma API RESTful desenvolvida em C# para gerenciamento de produtos, focada em boas práticas de desenvolvimento back-end.

## 💻 Sobre o Projeto

O **ProdutosAPI** é um sistema de back-end projetado para realizar o controle e a gestão de um catálogo de produtos. Este projeto foi desenvolvido para consolidar conhecimentos em construção de APIs com o ecossistema .NET, abordando desde a estruturação de rotas até a persistência de dados.

## ✨ Funcionalidades (Features)

* **[POST]** Cadastro de novos produtos.
* **[GET]** Listagem de todos os produtos cadastrados.
* **[GET]** Busca de um produto específico por ID.
* **[PUT/PATCH]** Atualização de dados de um produto existente.
* **[DELETE]** Remoção de produtos do sistema.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** C#
* **Framework:** ASP.NET Core (.NET 8.0)
* **Banco de Dados:** SQL Server
* **ORM:** Entity Framework Core
* **Documentação:** Swagger
